## ✨ Features

- **Real-time rates** — Live exchange data via [open.er-api.com](https://open.er-api.com)
- **145+ currencies** — Search by currency code or country name
- **Country flags** — Visual flag for every currency via [flagcdn.com](https://flagcdn.com)
- **Two-way conversion** — Type in either box; both update instantly
- **Swap button** — Switch currencies in one click with correct recalculation
- **No convert button needed** — Converts automatically as you type
- **Fully responsive** — Works great on mobile and desktop
